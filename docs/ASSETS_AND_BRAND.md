## 工程处置

- 手形光标和海岛 SVG 继续用于本地学习展示，以保存原仓库视觉价值。
- Dialog 的不规则路径继续保留，但每个实例生成独立 clipPath ID。
- 方正字体不进入默认库 CSS；只有显式引入 `legacy-font.css` 并添加 `.cute-ui-legacy-font` 才启用。
- 构建仍复制字体到 `dist/assets`，仅用于当前私有、本地学习构建；这不代表已获得发布授权。
- README、showcase footer 与 Storybook 文档均保留个人学习/非官方边界。

## 发布前停止条件

以下任一项未完成时，不得发布 npm、公开宣称开源或将素材复制到其他项目：

1. 确认四项资产的作者、来源和可再分发范围。
2. 对方正字体取得适用于目标发布方式的授权，或换成明确可分发字体。
3. 决定源码许可证，并确认许可证不与素材条款冲突。
4. 审核项目名称、品牌表述与视觉相似度。
5. 删除 `private: true` 前进行一次新的依赖、包内容和法律边界审查。
